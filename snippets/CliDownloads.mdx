Each release lists its binaries and their SHA256 checksums in a manifest at `https://sprites.dev/dl/client/<version>/manifest.json`. The commands below look up the latest version, so they don't need updating for each release.

<Tabs>
  <Tab title="macOS">
    Builds are published for Apple Silicon only. There is no Intel Mac build.

    ```bash Download
    VERSION=$(curl -fsSL https://sprites.dev/dl/client/latest)
    curl -fLo sprite "https://sprites.dev/dl/client/$VERSION/sprite-macos-aarch64"
    ```

    ```bash Verify checksum (recommended)
    shasum -a 256 sprite
    curl -fsSL "https://sprites.dev/dl/client/$VERSION/manifest.json" | grep -A3 '"macos-aarch64"' | grep digest
    ```

    The two hashes should match.

    ```bash Install
    chmod +x sprite
    sudo mv sprite /usr/local/bin/
    ```
  </Tab>

  <Tab title="Windows">
    <Tabs>
      <Tab title="x86-64">
        ```powershell Download
        $Version = (Invoke-RestMethod https://sprites.dev/dl/client/latest).Trim()
        New-Item -ItemType Directory -Force "$env:USERPROFILE\bin" | Out-Null
        Invoke-WebRequest -Uri "https://sprites.dev/dl/client/$Version/sprite-windows-x86_64.exe" -OutFile "$env:USERPROFILE\bin\sprite.exe"
        ```

        ```powershell Verify checksum (recommended)
        (Get-FileHash "$env:USERPROFILE\bin\sprite.exe").Hash.ToLower()
        (Invoke-RestMethod "https://sprites.dev/dl/client/$Version/manifest.json").platforms.'windows-x86_64'.digest
        ```

        The two hashes should match.

        ```powershell Add to PATH
        [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$env:USERPROFILE\bin", "User")
        ```
      </Tab>
