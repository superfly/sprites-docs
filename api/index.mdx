This section is the Sprites API reference, generated from the Sprites OpenAPI specification. For guides and worked examples, see [Working with Sprites](/sprites/working-with-sprites).

## Base URL

All requests are made against:

```
https://api.sprites.dev
```

## Authentication

Every request takes a bearer token:

```
Authorization: Bearer <token>
```

## Specification

Download the [OpenAPI spec](https://api.sprites.dev/openapi.json) to generate a client or explore the API in another tool.
